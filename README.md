Sobre o projeto

Este projeto consiste em um exercício de simulação de caixa eletrônico, desenvolvido como parte do meu aprendizado em programação.

O mesmo exercício foi registrado em duas versões: uma em arquivo TXT e outra implementada na linguagem C, mantendo a mesma lógica e funcionalidade.

Arquivos

* Versão TXT: representação original do exercício.
* Versão C: implementação do mesmo exercício utilizando a linguagem C.

Linguagem utilizada

* C (Linguagem de programação)

Objetivo

Praticar lógica de programação e desenvolver meus conhecimentos na linguagem C durante minha formação em Análise e Desenvolvimento de Sistemas (ADS).
